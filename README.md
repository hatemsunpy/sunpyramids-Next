# sunpyramids-Next

Next.js migration for Sun Pyramids Tours.

## Deployment boundary

- `https://sunpyramidstours.com` is still the legacy **Nuxt** production build.
- Next.js changes are visible only in this repo and the staging preview: `https://sunpyramids-next.vercel.app`.
- Current verified local preview: `http://localhost:3003`.
- `http://localhost:3000` is a stale old dev process — do not use for validation.
- See `docs/next-migration/deployment-boundary.md` for the full rule.
